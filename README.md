# 《凡人問道錄：一念掌天》 (88ckk)

融合《凡人修仙傳》與《一念逍遙》精華的古典水墨放置修仙網頁遊戲（支援手機與電腦瀏覽器直接遊玩）。

## 核心特色
- **☯️ 法體雙修與共鳴**：修法（練氣➔築基➔結丹➔元嬰➔化神➔返虛➔合體➔大乘➔真仙➔道祖）與煉體（通脈➔鍛骨➔煉腑➔元武➔神力➔破虛➔混元➔大成➔真武➔聖體）雙軌並進，同階觸發「法體共鳴 +30%」。
- **🌱 掌天藥園與地火丹房**：造化綠液催熟十階靈草，支援自由切換靈草種子、異火煉製極品雲紋丹與丹毒排毒機制。

- **🎰 機緣探寶與古寶注靈**：消耗探寶令抽取白、藍、紫、金、紅五階古寶，重複抽取自動升星（★），並可消耗靈塵注靈強化與啟動套裝共鳴。

- **📜 命格重塑**：首次切換免費，之後每次 300 靈石。
